# asenasecurity.com

Source for https://www.asenasecurity.com, served by GitHub Pages. The blog lives separately at https://blog.asenasecurity.com (repo `zenw01f.github.io`).

- `index.html`: home page
- `team.html`: Meet the Team
- `privacy.html`, `terms.html`: legal pages (shared styles in `assets/legal.css`)

## Versions

Each published version is tagged (for example `v1.0`). To restore one:

    git checkout v1.0 -- .
    git commit -m "Revert site to v1.0" && git push
